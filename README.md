## 규칙

화투 48장, 열두 달 × 넉 장. 손패 10장, 바닥 8장으로 시작합니다.
손에서 한 장을 내고 더미에서 한 장을 뒤집습니다. 짝은 **같은 월**끼리만 맞습니다.

### 점수

| 구분 | 점수 |
| --- | --- |
| 광 | 3광 3점 (비광이 끼면 2점) · 4광 4점 · 5광 15점 |
| 열끗 | 5장부터 1점, 한 장마다 +1 · 고도리(2·4·8월 새) 5점 |
| 띠 | 5장부터 1점, 한 장마다 +1 · 홍단·초단·청단 각 3점 |
| 피 | 10장부터 1점, 한 장마다 +1 · 쌍피는 2장 |

9월 국진은 **열끗과 쌍피 중 유리한 쪽**으로 자동 계산합니다.

### 특수 규칙

| 이름 | 조건 | 효과 |
| --- | --- | --- |
| 뻑 | 낸 패로 짝을 맞췄는데 뒤집은 패도 같은 월 | 석 장 모두 바닥에, 아무도 못 먹음 |
| 쪽 | 짝 없이 낸 패에 뒤집은 패가 붙음 | 두 장 획득 + 상대 피 1장 |
| 따닥 | 낸 패와 뒤집은 패로 각각 한 쌍씩 | 상대 피 1장 |
| 싹쓸이 | 차례가 끝났을 때 바닥이 빔 | 상대 피 1장 |
| 쓸 / 뻑 회수 | 같은 월 넉 장을 한 번에 | 상대 피 1장 |
| 폭탄 | 손에 석 장 + 바닥에 한 장 | 넉 장 획득 + 상대 피 1장 + 한 번 더 |
| 흔들기 | 손에 석 장 + 바닥에 없음 | 선언하면 최종 점수 2배 |
| 총통 | 받은 패에 같은 월 넉 장 | 즉시 10점 승 |

### 고 / 스톱

7점을 넘기면 고와 스톱 중 고릅니다. 고를 부르면 **이전보다 점수가 올랐을 때만**
다시 물어봅니다.

- 1고 +1점, 2고 +2점
- 3고부터는 고를 부를 때마다 ×2 — `(기본 + 2) × 2^(고−2)`
- 고를 불렀는데 상대가 먼저 스톱하면 **고박**으로 두 배

### 박

- **피박** — 진 쪽 피가 7장 미만이고 이긴 쪽이 피로 점수를 냈을 때
- **광박** — 진 쪽 광이 0장이고 이긴 쪽이 광으로 점수를 냈을 때
- **멍박** — 진 쪽 열끗이 0장이고 이긴 쪽이 7장 이상일 때

각각 최종 점수 ×2이고, 여러 개가 겹치면 모두 곱해집니다.

### 나가리

둘 다 패가 떨어지도록 아무도 7점을 못 내면 무승부입니다.

> 고스톱은 지방마다 규칙이 다릅니다. 여기 적힌 것이 이 구현이 따르는 규칙 전부입니다.

## 구조

```
index.html          판
cards.html          화투 48장 도감
css/style.css
assets/cards/       화투 48장 그림 (CC BY-SA 4.0, ATTRIBUTION.md 참고)
js/cards.js         48장 정의 (월·종류·띠 색·피 점수)
js/art.js           카드 앞/뒷면 조립 — 그림 위에 월 숫자와 고/열/쌍/단 표시
js/engine.js        규칙 엔진 — DOM을 모름, 시드로 재현 가능
js/ai.js            상대 — 엔진만 읽고 손패·더미는 못 봄
js/ui.js            렌더링과 진행 루프
js/main.js
test/engine.test.mjs
```

엔진은 순수합니다. 무작위성은 상태에 담긴 시드 PRNG뿐이라서,
같은 시드는 같은 판을 그대로 재현합니다.

## 개발

```bash
npm test          # node:test, 의존성 없음
npm start         # http://localhost:8777
```

정적 파일이라 서버 없이 `index.html`을 직접 열어도 되지만, ES 모듈을 쓰므로
`file://` 에서는 동작하지 않습니다.

테스트는 규칙 31건을 확인하고, 그 안에는 **시드 1000판 AI 대 AI 자동 대국**이 들어
있습니다. 매 수마다 48장이 전부 제자리에 있는지 검사하고, 모든 판이 끝까지 진행되는지
확인합니다.

브라우저 콘솔에서 `window.gostop`으로 현재 상태를 들여다볼 수 있습니다.
`gostop.pace`의 값을 0으로 만들면 애니메이션 없이 빠르게 진행됩니다.
